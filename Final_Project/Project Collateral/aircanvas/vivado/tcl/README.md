# Vivado Tcl Notes

The generated Vivado block design should be built from the course-approved Zybo Z7/Pcam 5C reference design. The design is expected to contain:

- Zynq processing system;
- clock/reset generation;
- Pcam/MIPI CSI-2 camera path;
- frame buffer or DMA path;
- HDMI output path;
- AXI GPIO or AXI-Lite registers for switches, LEDs, and fingertip metadata;
- custom RTL modules from `vivado/rtl`.

Do not commit generated IP output products until the team agrees on the exact Vivado version and board design.
