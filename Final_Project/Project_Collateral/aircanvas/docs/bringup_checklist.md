# Bring Up Checklist

## Vivado hardware

- [ ] Zybo Z7 board part and board files are installed.
- [ ] Pcam 5C is connected with the FFC in the correct orientation.
- [ ] Zynq processing system validates successfully.
- [ ] Camera I2C configuration path is available.
- [ ] Camera stream is visible in an ILA or test output.
- [ ] HDMI test pattern is displayed.
- [ ] Switches and LEDs are verified.
- [ ] Hardware preprocessing produces a valid candidate coordinate.
- [ ] Timing and utilization reports are saved.

## Vitis software

- [ ] UART output is visible.
- [ ] Frame buffers are allocated successfully.
- [ ] Hardware status and coordinates can be read.
- [ ] Fingertip coordinates are smoothed.
- [ ] A stroke can be created and retained.
- [ ] A closed shape turns on the status LED.
- [ ] Switch-based clear works.
- [ ] Optional keyboard support is tested only after the core path works.
- [ ] Optional sound sensing is tested only if the sensor interface is available.
